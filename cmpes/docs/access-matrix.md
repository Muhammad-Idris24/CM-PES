# Role Access Matrix

| Module | Administrator | Manager/Evaluator | Contractor |
| --- | --- | --- | --- |
| Dashboard | Full system overview | Evaluation overview | Own assignments/results |
| Users | Create, edit, deactivate | No access | No access |
| Contracts | Create, edit, upload documents, view | Create, edit, upload documents, view | View assigned only |
| Assignments | Create, edit, view | Create, edit, view | View own only |
| KPIs | Create, edit, view | Create, edit, view | View assigned contract KPIs |
| Evaluations | Create, review, approve, view | Create, review, approve, view | View assigned contract evaluations |
| Reports | Generate, view | Generate, view | View assigned contract reports |
| Notifications | View own | View own | View own |
| Audit Logs | View in admin/dashboard | No direct access | No access |
